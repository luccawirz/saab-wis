### Paint protector

> 🔧 [Online öffnen](https://saabwisonline.com/9-3-9440/2005/1-service/saab-service-eu/adjustment-replacement/paint-protector/)

#### Paint protector
**General**


    The paint protector may be left on the car for a maximum of three months before removal.


    The date of manufacture of the car is given on the vehicle card (422 means week 42 day 2).


    [/images/9-3-9440/img-d8/d890m005.svg](https://saabwisonline.com/images/9-3-9440/img-d8/d890m005.svg)

**Location**


   [/images/9-3-9440/img-f8/f845m002.svg](https://saabwisonline.com/images/9-3-9440/img-f8/f845m002.svg)


   Paint protector is fitted in the following locations:


| • | the sills (Aero) | | • | the boot lid/tailgate | | • | the bonnet | | • | the roof | | • | the driver's side rear door | **Removing**


   The paint protector may be removed with temperatures in the range 0 to +35°C; the most suitable temperature is +20°C. If the body and the ambient temperatures are above +35°C, park the car in the shade or cool it down with water until the body has attained a suitable temperature.

⚠️ **Important**
| Adhesive residue may fasten to the paintwork at high temperatures.
|
   The paint protector must be removed at least 48 hours before the car is shown to a customer so that any swelling has time to go down.

1. Loosen the corners of the paint protector. Use your hands only; no tools

2. Hold the paint protector as close as possible to the bodywork.

3. Pull parallel to the body surface at an even rate, do not jerk .

4. Wash the car with water and dry it

5. Make sure there is no adhesive residue remaining. If there is, remove it with petroleum spirit (low-aromatic petroleum hydrocarbon) or Isopropanol (Isopropyl alcohol). Use these sparingly and for short periods only.


   When the paint protector and any adhesive residue has been removed, there may be swelling in paintwork. This is normally temporary and will disappear within 48 hours.


### Road test

> 🔧 [Online öffnen](https://saabwisonline.com/9-3-9440/2005/1-service/saab-service-eu/adjustment-replacement/road-test/)

#### Road test
**Function checks**


    The road test is an important part of the service programme. Check the functionality of the various components and systems as described below.


| • | Lighting: Check front and rear lights, direction indicators, brake lights, high-level brake light, rear fog lights and number plate illumination. | | • | Ignition switch: Check that the gear-lever lock operates satisfactorily and that the key is easy to insert and remove. Check the parking position lock on cars with automatic transmission (certain markets only). | | • | Engine: Check function and noise level. Make sure the engine acceleration is normal. | | • | Clutch: Check the clutch disengagement and engagement positions. | | • | Manual gearbox: Check gearbox operation and noise level. | | • | Automatic transmission: Check the starting interlock, i.e. that the engine can be started only when the selector lever is in P or N, noise levels and shifting performance. | | • | Wheels: Check wheel balance and wheel roundness. | | • | Steering: Check the straight-ahead position of the steering wheel, directional stability and operation of the power steering system. | | • | Instruments and indicator lamps: Check the operation of instruments and indicator lamps. | | • | Brakes: Check brake pedal travel, handbrake lever travel (1-4 notches) and the efficiency of the brakes and handbrake. | | • | Cruise Control: Check the functionality of the Cruise Control system. | | • | Heating and ventilation unit: Check the operation of the A/C system and controls. When the outdoor temperature is so low that the A/C cannot be turned on, check its operation indoors. | | • | Wipers and washers: Check the washer jet pattern and wiper operation on the windscreen. | | • | Check that the clock shows the right time. | #### Bear in mind the customer's expectations!


     Wipe the steering wheel and gear lever clean and make sure that all other traces of pre-delivery inspection and service work have been removed.


     Return the driver's seat to its original position if it has been readjusted.

> 🔧 [Online öffnen](https://saabwisonline.com/9-3-9440/2005/1-service/saab-service-eu/adjustment-replacement/removable-towbar/)

#### Removable towbar
Clean the ball unit and its mounting as necessary. Check that the ball unit is easy to remove/fit and that it locks properly. For lubrication, use a base oil with anti-corrosion properties and a broad temperature range.

**Lubricating the detachable towbar from Bosal**

1. Clean and lubricate the coupling mechanism. Lubricate the pin on the top of the towbar as well as the lock cylinder.

2. Clean and lubricate the towbar bracket.


### Configuration of dipped beam/front fog lights

> 🔧 [Online öffnen](https://saabwisonline.com/9-3-9440/2005/1-service/saab-service-eu/adjustment-replacement/configuration-of-dipped-beam-front-fog-lights/)

#### Configuration of dipped beam/front fog lights
**Adjust**


    As part of the pre-delivery service, make the following settings on cars for the SE market. These settings prevent dipped beam and the front fog lights from being on at the same time.

1. Connect Tech 2 and select F0: Diagnose

2. Select the model year and car model.

3. Select F4: All

4. Select " Most Common Adjustments"

5. Select " Fog Lights Front"

6. Press the " Select" button

7. Select " Pos 1 (and 2 if High Beam) (Special)"

8. For programming, select OK ⚠️ Note If the car is not configured for fog lights but fog lights are installed, the message "Fog lights not installed!" will appear in Tech2.


### Advanced voice recognition

> 🔧 [Online öffnen](https://saabwisonline.com/9-3-9440/2005/1-service/saab-service-eu/adjustment-replacement/advanced-voice-recognition/)

#### Advanced voice recognition
Only one language is activated in cars with the navigation system and advanced voice recognition. Accordingly, the appropriate language for the market must be activated prior to delivery as described below.

1. From Tech 2 select: Service Programming System (SPS)

2. Request control module data: Model year -> 2005 Model -> Saab 9-3 Sport (9440) System -> Body Body -> ICM3 (OCP)

3. Finish reading out the control module data and connect Tech 2 to a computer with TIS2000.

4. Start TIS2000. Select Service Programming System

5. Select Tech 2 and continue. Confirm the VIN. Make sure that the correct control module has been selected.

6. Select Language. Select the desired language from the menu. If ”M3318: ECU already contains the latest program version. Reprogramming not possible.” appears, the ICM3 already contains the correct language. Finish.

7. If this message does not appear, continue by selecting ”Next ->”.

8. Download the new language to Tech 2.

9. Disconnect Tech 2 from the computer and connect it to the car.

10. Remove the navigation disc from the DVD player in the car and insert the CD with TIS2000 ICM3 Edition 2004-1 or later version of TIS2000 ICM3.

11. From Tech 2 select: Service Programming System (SPS). Select Program ECU. Wait until the update is finished. Progress is not shown on Tech 2 but on the ICM3 display.
